# Prismal: Name and Identity

## Name

**Prismal** (pronounced "PRIZ-mal")

A prism takes a single beam of light and separates it into a spectrum. Prismal applies the
same idea to models: one underlying model is projected into many representations, such as
equations, graphs, spatial scenes, animations, experiments and data.

### Selection criteria

- **Pronounceable** and easy to remember.
- **ASCII only.** Easy to type, search and use in URLs, package names and CLI commands.
- **Usable as an identifier** for the crate, repository and command: `prismal`.
- **Domain neutral.** Not tied to physics, mathematics, chemistry or visualization.
- **Reflects the architecture.** A single model, many projections.
- **Extends to an ecosystem.** Prismal Language, Prismal Runtime, Prismal Studio.

### Names considered

| Name | Outcome |
|---|---|
| Prism | Rejected. Already used by the PRISM probabilistic model checker and its modeling language. |
| Primal | Rejected. Arose from an autocorrect error; less connected to the projection concept. |
| Prismμ | Rejected as the primary name. Requires a non-ASCII character and a separate ASCII form (`prismu`) for packages and commands, and the meaning of μ needs explanation. |
| Prismal | **Adopted.** |

### Use of μ

The μ symbol is kept as an optional element of the visual identity. It can stand for the
minimal semantic model at the core of the language:

```text
model -> μ -> view
```

## Tagline

**Primary (technical):**

> **One model. Many representations.**

The primary tagline states the core architecture directly and is the default for the
language, documentation and repository. The secondary tagline suits introductory and

## Descriptions

### Project description

**Prismal** is a modeling language for mathematics, science and interactive systems.

Define a model once, then simulate it, observe it, interact with it and express it through
different representations, from equations and graphs to spatial scenes, animations,
experiments and data.

**One model. Many representations.**

Built to be extensible, composable and grounded in a small semantic core.

### Short bio

Prismal: a modeling language for mathematics, science and interactive systems.
